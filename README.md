# Kartu Kosakata · 印尼语单词卡

一个纯前端的印尼语背单词卡片应用，单文件运行，可部署到 GitHub Pages，
支持在手机上"添加到主屏幕"后像 App 一样全屏使用。

## 怎么用

打开网页后：

- 点击卡片，或按空格键翻面。词根卡的背面是词性、最多 4 个重要衍生词（各配一个用例）、
  辨析和例句；词组卡的背面是逐词直译、用法提示和例句
- 顶部一行标签按分类筛选，一张卡可以带多个分类（比如 bumi 同时是「名词」和「教会」）
- 左右箭头键 / ← → 按钮切换上一张、下一张
- 按 `1` 或点击"再练一次"：标记为还需要再练
- 按 `2` 或点击"记住了"：标记为已掌握
- 点击 ⇄ 按钮打乱当前词库的顺序
- "已掌握"的进度会自动保存在本机浏览器（localStorage），下次打开自动恢复；
  想重新开始时，点击底部的"清空进度"

## 词典

顶部切到"词典"页，输入一个印尼语词就能查。查询结果包含词根、IPA 发音、核心释义、
三个常见短语、两个例句，以及完整的衍生词列表（每个带发音、释义、短语、例句）。

- 查过的词会存进词库。再查同一个词，或者查它的任何一个衍生词，直接读库，不再调 AI
- 报告底部可以选分类，一键把这个词转成学习卡，进入卡片页的牌组
- 词库列表可以按查询次数筛：1 次 / 2-5 次 / 5 次以上，反复查的词一眼看得到
- "日历"页按日期倒序列出查过的所有词。实心的是当时真调了 AI，描边的是命中了词库

查词要一个 Gemini API 密钥。在 [aistudio.google.com/apikey](https://aistudio.google.com/apikey)
用 Google 账号免费建一个，不用绑卡，然后填进底部同步设置里的"Gemini API 密钥"。
填过一次之后会跟同步码一起存，换设备自动带过去。

## 手机上添加到主屏幕

- **iPhone(Safari)**：打开网页 → 分享按钮 → "添加到主屏幕"
- **Android(Chrome)**：打开网页 → 右上角菜单 → "添加到主屏幕" / "安装应用"

添加后会以独立图标打开，全屏显示，不带浏览器地址栏。

## 本地开发

这是纯静态页面，没有构建步骤。因为用了 ES module 的相对导入，需要起一个本地静态
服务器才能预览（直接双击打开 `index.html` 会加载不了模块）：

```bash
python3 -m http.server 8000
```

往词库里加词的规范见桌面的《词库导出规则.md》。加完跑一次校验：

```bash
node tools/check-data.mjs
node --test tools/*.test.mjs
```

## 文件说明

- `index.html` — 应用本体（HTML + CSS + JS 全部在一个文件里）
- `dict-core.mjs` — 词典的纯函数（归一化、索引、分桶、转卡片、提示词与 schema），浏览器和测试共用
- `manifest.json` — PWA 清单，让手机可以把它当作一个独立 App 安装
- `tools/check-data.mjs` — 词库校验脚本，改完词库跑 `node tools/check-data.mjs`
- `docs/superpowers/` — 设计文档、实施计划、迁移清册
