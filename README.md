# Kartu Kosakata · 印尼语单词卡

一个纯前端的印尼语背单词卡片应用，单文件运行，可部署到 GitHub Pages，
支持在手机上"添加到主屏幕"后像 App 一样全屏使用。

## 怎么用

打开网页后：

- 点击卡片，或按空格键翻面。词根卡的背面是词性、最多 4 个重要衍生词（各配一个用例）、
  辨析和例句；词组卡的背面是逐词直译、用法提示和例句
- 顶部一行标签按分类筛选，一张卡可以带多个分类（比如 bumi 同时是「名词」和「教会」）
- 左右箭头键 / ← → 按钮切换上一张、下一张
- 按 `1` 或点击"再练一次"：标记为还需要再练
- 按 `2` 或点击"记住了"：标记为已掌握
- 点击 ⇄ 按钮打乱当前词库的顺序
- "已掌握"的进度会自动保存在本机浏览器（localStorage），下次打开自动恢复；
  想重新开始时，点击底部的"清空进度"

## 手机上添加到主屏幕

- **iPhone(Safari)**：打开网页 → 分享按钮 → "添加到主屏幕"
- **Android(Chrome)**：打开网页 → 右上角菜单 → "添加到主屏幕" / "安装应用"

添加后会以独立图标打开，全屏显示，不带浏览器地址栏。

## 本地开发

这是纯静态页面，没有构建步骤，直接用浏览器打开 `index.html` 即可预览，
或者起一个本地静态服务器：

```bash
python3 -m http.server 8000
```

往词库里加词的规范见桌面的《词库导出规则.md》。加完跑一次校验：

```bash
node tools/check-data.mjs
node --test tools/*.test.mjs
```

## 文件说明

- `index.html` — 应用本体（HTML + CSS + JS 全部在一个文件里）
- `manifest.json` — PWA 清单，让手机可以把它当作一个独立 App 安装
- `tools/check-data.mjs` — 词库校验脚本，改完词库跑 `node tools/check-data.mjs`
- `docs/superpowers/` — 设计文档、实施计划、迁移清册
