# 词根卡 + 固定词组卡 重构设计

日期：2026-08-07
项目：kartu-kosakata（印尼语单词卡，纯前端单文件）

## 背景

当前 `index.html` 的 `DATA` 里有 271 条卡片，一条卡片 = 一个词形。问题是词形混杂：

- 真词根：`diam`、`bukit`、`dosa`、`marah`、`berat`
- 派生词：`mengatakan`、`menceritakan`、`pemasok`、`menghitung`、`mengusir`、`mengabulkan`、`sejumlah`、`mendesak`、`suruhlah`
- 外来词（无印尼语派生形态）：`musik`、`metode`、`pabrik`
- 本已是词组：`kali terakhir`

只背词根不够——同一个词根派生出的词意思差很远（`belajar` 学 / `mengajar` 教 / `pelajar` 学生 / `ajaran` 教义），不把重要衍生词一起记住，词根等于白背。反过来，把每个派生词都当独立卡片背，又丢掉了词根这条主线，且卡片数量爆炸。

同时，印尼语有大量固定搭配（`air terjun` 瀑布、`gempa bumi` 地震、`satu demi satu` 一个一个），字面拆解不等于实际意思，必须整体记忆。这类内容目前散落在各卡的 `coll` 字段里，从来没有被单独考核过。

## 目标

1. 卡片以**词根**为单位组织，标注词根词性，每张带 1~2 个按重要度精选的衍生词，每个衍生词配一条词组或例句。
2. 新增**固定搭配词组卡**类型。
3. 重整现有 271 条词库为这两种卡片。
4. 在桌面输出一份新的《词库导出规则.md》，规范以后的取词。

## 非目标

- 不做间隔重复 / SM-2 算法。掌握状态仍是二元的「记住了 / 再练一次」。
- 不做词库的外部数据源接入。数据仍然内联在 `index.html` 的 `DATA` 数组里。
- 本轮不联网补充新词组，词组卡只从现有 `coll` 字段抽取。

## 数据模型

新增 `t` 字段区分卡片类型，取值 `"root"` 或 `"phrase"`。`t` 与原有的分类字段 `c`（高频/教会/工作/…）是两个正交维度，可叠加筛选。

### 词根卡 `t:"root"`

```js
{
  t: "root",
  w: "ajar",                          // 词根本身，卡片正面
  pos: "动词根（不单用）",              // 词根词性
  p: "a-jar 阿-乍",                    // 音节切分 + 中文谐音
  zh: "教导",                          // 词根本义
  c: "学习",                           // 原有分类
  der: [                              // 衍生词，1~2 个，按重要度排序
    { w: "mengajar", zh: "教、授课",   ex: "mengajar di sekolah 在学校教书" },
    { w: "ajaran",   zh: "教义、道理", ex: "ajaran sesat 异端" }
  ],
  syn: "belajar 学 / mengajar 教，一根两向；pelajar 学生 / pengajar 教师",
  ex: "Yesus mengajar orang banyak.|耶稣教导众人。"
}
```

字段说明：

| 字段 | 必填 | 说明 |
|---|---|---|
| `t` | 是 | 固定 `"root"` |
| `w` | 是 | 词根裸形，不带任何词缀 |
| `pos` | 是 | 词根词性，见下方词性标注表 |
| `p` | 是 | 音节切分 + 中文谐音，沿用现有写法 |
| `zh` | 是 | 词根本义。词根若不能单用，`pos` 里注明「不单用」 |
| `c` | 是 | 原有分类标签，取值不变 |
| `der` | 否 | 0~2 个衍生词。外来词/无派生词根可为空数组 |
| `der[].w` | 是 | 衍生词完整词形 |
| `der[].zh` | 是 | 衍生词中文释义 |
| `der[].ex` | 是 | 一条词组或短例句，印尼语在前、中文在后，空格分隔 |
| `syn` | 否 | 辨析、易混提示。沿用现有写法，`⚠️` 开头表示警告 |
| `ex` | 是 | 完整例句，格式 `印尼语\|中文`（竖线分隔，沿用现有格式） |

**衍生词的构成式不显示在卡片上。** 即不出现 `ber- + ajar`、`meN- + ajar + -kan` 这类中间列——那是查词典时的分析过程，背诵时只需要「词形 → 中文 → 一个用例」。

**衍生词重要度排序判据**（取前 1~2 个）：

1. 用户实际语境（教会讲道、印尼工厂采购工作、日常生活）里出现频率高的优先。
2. 与词根本义**偏离最大**的优先——偏离小的能猜出来，不值得占位（`ajaran` 教义 > `pengajaran` 教导这件事）。
3. 同一词根下，优先选**不同词缀家族**的（一个 `meN-` 动词 + 一个 `pe-/-an` 名词），而不是两个都选 `meN-` 系。
4. 已经独立成词、词典单列词条的优先。

### 词性标注表

词根卡的 `pos` 从以下取值，括号内补充说明可自由发挥：

- `动词根` — 可直接作动词或加词缀成动词（`ajar`、`usir`、`hitung`）
- `名词` — （`bukit`、`dosa`、`pabrik`）
- `形容词` — （`berat`、`lemas`、`marah`）
- `副词` / `连词` / `介词` / `数词` / `代词` — 虚词类（`lalu`、`demi`）
- `量词` — （`kali`）
- 不单用的词根，在词性后加「（不单用）」，如 `动词根（不单用）`
- 外来词若形态上不参与印尼语派生，词性照常标，`der` 留空

### 词组卡 `t:"phrase"`

```js
{
  t: "phrase",
  w: "air terjun",                    // 整个固定搭配，卡片正面
  p: "a-ir ter-jun",                  // 音节切分
  zh: "瀑布",                          // 整体释义
  c: "地形",                           // 原有分类
  lit: "air 水 + terjun 跳下",          // 逐词直译
  note: "固定组合，不说 air jatuh；terjun 单用是「跳下、投身」",
  ex: "Kami pergi melihat air terjun.|我们去看瀑布。"
}
```

字段说明：

| 字段 | 必填 | 说明 |
|---|---|---|
| `t` | 是 | 固定 `"phrase"` |
| `w` | 是 | 完整固定搭配 |
| `p` | 是 | 音节切分，中文谐音可省 |
| `zh` | 是 | 整体释义。**不是**逐词释义之和 |
| `c` | 是 | 原有分类标签 |
| `lit` | 是 | 逐词直译，格式 `词A 义A + 词B 义B` |
| `note` | 否 | 用法提示：能不能替换成分、固定程度、常见错法 |
| `ex` | 是 | 完整例句，格式 `印尼语\|中文` |

**词组卡的收录门槛**：整体意思不能由逐词直译推出，或搭配固定到换词就错。`mendengarkan musik`（听音乐）这种自由组合不收；`air terjun`（水+跳下=瀑布）、`gempa bumi`（震+地=地震）、`berat hati`（重+心=不情愿）、`satu demi satu`（一+以…之名+一=一个一个）这种收。

## 词库迁移

271 条现有卡片按下述规则重整。这是一次性的内容改造，不是可自动化的机械转换——每条都要人工判断，但有明确规则可循：

1. **派生词卡 → 并入词根卡的 `der`**。原卡的 `zh` 成为 `der[].zh`，原卡的 `coll` 里挑一条最典型的成为 `der[].ex`，原卡的 `syn` 和 `ex` 上提到词根卡。已识别的：`mengatakan→kata`、`menceritakan→cerita`、`pemasok→pasok`、`menghitung→hitung`、`mengusir→usir`、`mengabulkan→kabul`、`sejumlah→jumlah`、`mendesak→desak`、`suruhlah→suruh`。全量扫描时按词缀特征（`me-/meN-`、`ber-`、`pe-/peN-`、`-an`、`-kan`、`-i`、`se-`、`ter-`、`-lah`）识别其余。
2. **同一词根有多张派生词卡** → 合并成一张词根卡，`der` 从这些派生词里按重要度判据选 1~2 个，落选的降级到 `syn` 里一句带过。
3. **已是词根的卡** → 直接转 `t:"root"`，补 `pos`，从原 `coll` 里提取衍生词填 `der`。
4. **外来词** → 转 `t:"root"`，`der` 留空或只放一条，原 `coll` 里的固定搭配抽成独立词组卡。
5. **本已是词组的卡**（如 `kali terakhir`）→ 转 `t:"phrase"`。
6. **全量扫 `coll` 字段抽词组卡** → 按收录门槛筛选，够格的立独立词组卡。词组卡立了以后，原词根卡的 `coll` 内容不再重复保留（`coll` 字段整体废弃，其内容分流到 `der[].ex`、`syn`、词组卡三处）。

预计产出规模：约 170 张词根卡 + 约 50 张词组卡。实际数字以迁移结果为准。

## 应用改动

### 卡片 id

现在 `deck = DATA.map((d,i)=>({...d,id:i}))`，id 是数组下标。重整后下标全变，进度会错位。

改为稳定字符串 id：`root:ajar`、`phrase:air-terjun`（`w` 转小写、空格转连字符）。同形异义词根（同一拼写、两个不相干的义项）追加序号区分，如 `root:bisa-1`（能够）、`root:bisa-2`（毒液）。localStorage key 从 `kosakata-known` 换成 `kosakata-known-v2`，Firebase 文档字段同步换。

**旧进度全部作废**，不做迁移。用户已确认：已掌握的一律当成没掌握，记录推翻重来。旧 key 不读取、不删除，留在那儿无害。

### 筛选

顶部现有一行分类标签（全部/高频/教会/…）保持不变。上方新增一行类型切换：`全部` / `词根` / `词组`。两个维度**叠加**生效——选「词组 + 教会」得到教会类的词组卡。

`filter()` 从单条件改成两条件与运算。类型选中状态和分类选中状态各存一个变量。

### 渲染

`render()` 现在按固定模板拼背面。改成按 `d.t` 分两套模板：

- `root`：词性 → 本义 → 衍生词列表（每条：词形 / 中文 / 用例）→ 辨析 → 例句
- `phrase`：释义 → 逐词直译 → 用法提示 → 例句

`ex` 字段的 `印尼语|中文` 拆分逻辑两种卡片共用，不动。

### 已掌握列表

`renderKnownList()` 按 id 从 `deck` 里查，id 改成字符串后逻辑不变，只是查找键类型变了。

## 测试

纯前端单文件项目，无测试框架。验证靠：

- 数据自检脚本（临时，不入库）：遍历 `DATA` 检查必填字段齐全、`t` 取值合法、`ex` 含竖线、`der` 长度 ≤ 2、id 无重复。
- 浏览器手测：类型切换 × 分类切换的叠加筛选、两种卡片背面渲染、翻面、上一张下一张、打乱、标记掌握、刷新后进度恢复、清空进度。
- Firebase 同步：换 key 后新旧设备各自从零开始，不互相污染。
